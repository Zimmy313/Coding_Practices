# Nano Quick Reference

## Open File

```bash
nano filename.txt
nano ~/.ssh/config
```

## Essential Shortcuts

- `^X`: exit.
- `^O`: write out (save).
- `^W`: search.
- `^\`: replace.
- `^K`: cut current line.
- `^U`: paste previously cut text.
- `^G`: help.

`^` means `Ctrl`.

## Common Flow

1. Open file with `nano file`.
2. Edit content.
3. Save with `Ctrl+O`, then press `Enter`.
4. Exit with `Ctrl+X`.
